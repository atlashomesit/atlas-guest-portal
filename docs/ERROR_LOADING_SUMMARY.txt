===============================================================================
ERROR TYPES (4 CATEGORIES)
===============================================================================

1. VALIDATION (User input invalid)
   - buildValidationError(fieldName, reason)
   - buildMissingFieldError(fieldName)
   - buildRateLimitError(seconds)
   - Message tone: "Fix and retry"
   - Recovery: RETRY, CONTACT_SUPPORT

2. NETWORK (Connectivity / server unreachable)
   - buildNetworkError()
   - buildTimeoutError()
   - buildOfflineError()
   - Message tone: "Check connection, try again"
   - Recovery: RETRY, CONTACT_SUPPORT

3. PERMISSION (No access to resource)
   - buildUnauthorizedError()
   - buildForbiddenError(resourceType)
   - buildPermissionDeniedError(action, resourceType)
   - Message tone: "Sign in or request access"
   - Recovery: SIGN_IN, REQUEST_ACCESS, CONTACT_SUPPORT

4. UNKNOWN (Server crash, unhandled error)
   - buildNotFoundError(itemType)
   - buildServerError(status, contactEmail)
   - buildUnknownError()
   - Message tone: "Try again or contact support"
   - Recovery: RETRY, CONTACT_SUPPORT

DOMAIN-SPECIFIC:
  - buildPaymentError(reason)
  - buildBookingError(reason)
  - buildPropertyError(action)

===============================================================================
LOADING PATTERNS (6 SHAPES)
===============================================================================

1. SKELETON-CARD (Grid of items)
   - Usage: Search results, listings grid
   - Structure: Image + content lines
   - Stagger: auto via nth-child (100ms offset)

2. SKELETON-LIST (Vertical items)
   - Usage: Bookings, transactions
   - Structure: Thumbnail + content lines
   - Stagger: cascade effect

3. SKELETON-FORM (Form fields)
   - Usage: Checkout, settings
   - Structure: Fields + buttons
   - No stagger (all together)

4. SKELETON-TABLE (Tabular data)
   - Usage: Analytics, transactions
   - Structure: Headers + rows
   - Stagger: uniform rows

5. SKELETON-GRID (Small items)
   - Usage: Amenities, features
   - Structure: 4-column compact
   - Stagger: cascade effect

6. SPINNER (Inline rotation)
   - Usage: Button actions, quick fetches
   - Structure: Rotating border
   - No stagger (single)
